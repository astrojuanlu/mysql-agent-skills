# pairedstats

Paired statistics for cost campaigns: exact sign-flip permutation,
Wilcoxon (Pratt), paired t, exact McNemar, Jeffreys/Clopper-Pearson
upper bounds, Miettinen-Nurminen CI on the rate difference. Numbers are
validated against external ground truth only (published tables, closed
forms, brute force) — see `tests/`.
